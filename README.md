# こえメモ（自分用ボイスレコーダー）

ブラウザだけで動く、無料の録音・文字起こしツールです。インストールも登録も要りません。

## できること
- 録音・一時停止・再開。経過時間と音量メーターを表示
- 話した内容をその場で文字にする（リアルタイム文字起こし、Chrome / Edge のみ）
- 録音はブラウザ内に自動保存し、一覧から検索・再生できる
- 文字起こしの時刻をクリックすると、その場面から再生
- 音声ファイル（.webm / .m4a）とテキスト（.txt）の保存、コピー
- 途中でタブが落ちても、5秒ごとに保存した分から復元
- 録音中は画面がスリープしない

## 使い方（PC）
文字起こしを確実に動かすため、`http://localhost` で開いてください。

```bash
cd voice-recorder
python3 -m http.server 8000
```

Chrome で http://localhost:8000 を開き、マイクの使用を許可します。
（`index.html` をダブルクリックして開いても録音はできます。ただし文字起こしが使えない場合があります。）

## スマホで使う
スマホでマイクを使うには HTTPS が必要です。無料の GitHub Pages に `index.html` を置けば、
`https://<ユーザー名>.github.io/...` を開くだけで使えます。録音はその端末のブラウザ内に保存されます。

## 注意
- 録音データは**そのブラウザの中だけ**に保存されます。ブラウザのデータを消すと録音も消えるので、大事な録音は「音声を保存」で書き出してください。
- リアルタイム文字起こしはブラウザの音声認識機能を使います。Chrome では音声が Google のサーバーに送られて処理されます（無料）。社外秘の会議では、文字起こしをオフにして録音だけにすることもできます。
- 会議を録音するときは、参加者の同意を取ってください。
